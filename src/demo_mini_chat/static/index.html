IDEA CLAVE

El modelo no recibe palabras: recibe tokens.

Para cada paso produce scores crudos (logits). Softmax transforma esos scores en una distribución que suma 100%. Después se selecciona un token y el ciclo comienza de nuevo.

Ver un poco más técnico
texto → tokenizer → ids → modelo → logits
logits / temperatura → softmax → probabilidades
probabilidades → muestreo (o argmax) → token
